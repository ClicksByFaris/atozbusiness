# Abu Dhabi Typing Center - CMS Content Guide

This guide explains how to enter **Typing Center Services** into the Sanity CMS. Use these examples to ensure all services (Visa, Emirates ID, Medical, etc.) are entered correctly.

## 1. General Info
*Basic settings for the service.*

| Field Name | Description | Typing Center Example |
| :--- | :--- | :--- |
| **Service Name** | The official name of the service. | `Family Visa Renewal - Abu Dhabi` |
| **Slug** | The URL-friendly version (auto-generated). | `family-visa-renewal-abudhabi` |
| **Category** | Classification of the service. | `Visa Services` or `Emirates ID` |
| **Featured Service** | Check this for your most popular services. | `True` (for Family Visa, Golden Visa) |
| **Order** | Number to control sorting order. | `1` (Most important), `2`, `3`... |
